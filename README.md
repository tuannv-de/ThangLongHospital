
# **Thang Long Hospital**
Mô tả: Một dự án sử dụng Spark để chạy mô hình học máy và áp dụng nó trong việc chuẩn đoán khả năng (%) mắc bệnh tim , triển khai nó thành chức năng trên website.  
Ngoài ra cung cấp thêm các chức năng đặt lịch khám, quản lý lịch khám, quản lý bác sĩ, bệnh nhân, ..

Chức năng
- hỗ trợ bác sĩ trong việc chuẩn đoán bệnh tim áp dụng mô hình học máy Random forest được xử lí trên Apache Spark (local)
- chức năng giúp người bệnh đặt lịnh khám với bác sĩ,
- hỗ trợ bác sĩ quản lý đơn đăng ký khám

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
mở web ở http://localhost:8000
```
